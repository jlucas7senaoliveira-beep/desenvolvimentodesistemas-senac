Uso das Condicionais IF no JavaScript

A estrutura if permite executar um bloco de código apenas quando uma condição é verdadeira. 

let idade = 18;

if (idade >= 18) {
    console.log("Maior de idade");
}

Neste exemplo, a mensagem "Maior de idade" será exibida somente se a variável idade for maior ou igual a 18.

Também é possível utilizar else e else if para criar decisões mais complexas.
