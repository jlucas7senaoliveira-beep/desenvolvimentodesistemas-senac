# SISTEMA DE RH

## Problema
A empresa tem que controlar o numero de funcionarios controle de ferias e de jornada
## Objetivo
criar um sistema para organizar e manipular as horario de ponto e numero preciso de entrada e saida de cada funcionario
## Usuários
funcionarios, estagiario 
## Regras de Negócio
funcionario não podera tirar 30 dias de ferias seguidas
as ferias so poderão ser tiradas de 15 dias 
e não poderá tirar ferias no mesmo periodo que o mesmo colega do mesmo setor
tera 1hr e 30 minutos de almoço (com limite maximo de 10 minutos)
caso passe do tempo estipulado a cada minuto sera descontado 0,50 centavos
## Requisitos Funcionais
O sistema deve permitir cadastrar funcionarios .
O sistema deve permitir registrar entrada e saida dos funcionarios.
3. O sistema deve permitir registrar agendamentos.
4. O sistema deve registrar a ausensia do funcionario.
5. O sistema deve permitir consultar os agendamentos das ferias.
6. O sistema deve descontar os atrasados sobre o salario.
## Requisitos Não Funcionais
1. O sistema deve ter interface simples.
2. O sistema deve funcionar em computadores e celulares.
3. O sistema deve proteger os dados dos usuários.
4. O sistema deve carregar rapidamente.
5. O sistema deve ter layout responsivo.
